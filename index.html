// open source

Open Source Tools

TMPAnimatedText

GitHub ↗

Unity package for animated TextMesh Pro text. Wrap text in [anim] tags to apply effects — syntax similar to Godot's RichTextLabel. Installs via UPM.

"com.lisachidem.tmpanimated": "https://github.com/lisachidem/TMPAnimatedText.git?path=TMPAnimatedEffects"
C# Unity TextMesh Pro MIT

lisas-eventbus

GitHub ↗

Lightweight event bus package for Unity. Decouples systems without direct references — built to handle the cross-system messaging patterns that come up in every game.

// subscribe
EventBus<OnPlayerDied>.Subscribe(HandleDeath);
// publish
EventBus<OnPlayerDied>.Publish(new OnPlayerDied());
C# Unity Architecture MIT

lisas-custom-ui

GitHub ↗

Collection of reusable Unity UI scripts extracted from shipped projects. Covers common patterns — modals, animated panels, progress bars — that Unity's built-in UI doesn't handle cleanly.

C# Unity UI MIT

lisas-prime-tween-extensions

GitHub ↗

Extensions for the PrimeTween library — custom easing curves, sequence helpers, and shortcuts built up across multiple shipped Unity titles.

C# Unity PrimeTween MIT
